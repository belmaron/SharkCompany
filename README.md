# Shark Company

Site da Shark Company, a marca de produtos da Atlética Tubarões UFRJ.

- `index.html` — o site pronto (abra no navegador ou publique com GitHub Pages).
- `assets/` — fotos das peças, recortes do cardume e logos.
- `src/site.html` — código-fonte da página.
- `build.py` — gera `index.html` a partir de `src/site.html`:

```bash
python3 build.py assets/views/manifest.json
```
